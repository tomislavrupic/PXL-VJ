# PXL VJ

A native Apple Silicon live visual instrument. This repository hosts its landing
page and the verified release downloads.

- **Website:** https://tomislavrupic.github.io/PXL-VJ/
- **Mac download:** https://github.com/tomislavrupic/PXL-VJ/releases/download/v0.3.0/PXL-VJ-0.3.0-mac-arm64.zip
- **Matching native app and iPad source:** https://github.com/tomislavrupic/PXL-VJ/releases/download/v0.3.0/PXL-VJ-0.3.0-source.tar.gz

## Release 0.3.0 (6)

Developer ID signed, hardened runtime, Apple notarized and ticket stapled.
Apple Silicon · macOS 14+. The exact application ZIP and corresponding native
source are release assets; GitHub's automatically generated source archives
contain this website repository only.

Four-layer clip mixing, music-reactive Metal effects, beat-triggered random
video cuts, GPU pixel sorting, 3D UV texture projection/depth controls,
black/white and animated layer masks, surface mapping, Ableton Link, Blackmagic
video output and an iPad controller. AI clip generation uses the separately
installed ALi Imagine app; continuous AI diffusion is not in this release.

PXL VJ native source is GPL-2.0-or-later. Full licenses and third-party notices
are included in the matching source archive and Mac app. No pairing secret or
development signing profile is distributed.

## Website maintenance

Static HTML/CSS/JS at the repository root. GitHub Pages publishes main from /.
All screenshot and asset URLs are relative so the project path works correctly.
Release binaries stay in GitHub Releases. Update downloads/release.json,
SHA256SUMS.txt, and the explicit release links when publishing a new version.
